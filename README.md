# Лабораторная работа №19. Введение в JavaScript. Сравнение с C#
## ФИО: Жанатпаева Дианара Мурадымовна Группа: ИСП-232 Дата: 09.03.2026
## Краткое описание работы
Этот проект представляет собой небольшой обзор основных возможностей JavaScript. В нём реализован быстрый проход по базе языка: рассмотрены базовые конструкции, такие как переменные, циклы, условия, функции и объекты. Проект создан в учебных целях для закрепления базовых знаний JavaScript и демонстрации простых примеров работы с языком.
## Цель работы:
- Познакомиться с языком программирования JavaScript;
- Понять его место в web-разработке;
- Сравнить базовые концепции JavaScript и C#;
- Научиться запускать JavaScript-код в браузере и через Node.js.
